ผู้ประเมินหลัก: -

อัปเดตล่าสุดเมื่อ: -
คะแนนเก็บระหว่างเรียน 0.0 / 50
คะแนนสอบกลางภาค 0.0 / 20
คะแนนสอบปลายภาค 0.0 / 30
คะแนนรวมและเกรด 0.0 (เกรด -)
รายละเอียดคะแนนย่อยเชิงลึก
คะแนนสมุดและการส่งงาน 0 คะแนน

คะแนนวัดความสม่ำเสมอในการนำเสนอผลงาน สมุดจด ความเป็นระเบียบวินัย และการเรียนรวมกัน (คะแนนเต็ม 50 คะแนนแปรผันตามครูผู้สอน)

คะแนนงาน / ใบงานกิจกรรม 0 คะแนน

คะแนนสอบย่อย คะแนนการรวมกลุ่ม และงานกิจกรรมพิเศษภายในห้องเรียนที่ได้มอบหมายตลอดภาคเรียนนี้

การสอบข้อเขียนภาคทฤษฎี 0 คะแนน

คะแนนสอบกลางภาค (Midterm) คะแนนสอบปลายภาคเรียน (Final) ของวิชาซึ่งเป็นเกณฑ์แกนกลางร่วมของกลุ่มสาระ

หมายเหตุความเข้าใจเรื่องเกรดเฉลี่ย:

ผลการเรียนดังกล่าวเป็นคะแนนเบื้องต้นที่ถูกบันทึกเข้าระบบออนไลน์ตามช่วงเวลาของสัปดาห์ปัจจุบันเท่านั้น หากคุณครูประจำวิชามีการปรับปรุง คะแนนจะมีการเปลี่ยนแปลงตามวันอัปเดตข้างต้น หากพบข้อมูลคลาดเคลื่อนหรือข้อซสัยในคะแนนย่อยสามารถติดต่อผู้สอนโดยตรง
